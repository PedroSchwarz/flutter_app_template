# flutter_app_template

[![Powered by Mason](https://img.shields.io/endpoint?url=https%3A%2F%2Ftinyurl.com%2Fmason-badge)](https://github.com/felangel/mason)

A robust app template for Flutter apps

## Getting Started 🚀

Init mason

``` mason init ```

Add brick path to mason.yaml:
```
flutter_app_template:
    git:
      url: https://github.com/PedroSchwarz/flutter_app_template.git
```

Get brick

``` mason get  ``` OR

``` mason upgrade ``` when updating a brick

Make brick

``` mason make flutter_app_template ```
